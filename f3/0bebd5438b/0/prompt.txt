# Instructions: Dual-Feed Strategy Backtests (HL + CB Combined)

## Context

CB Live and HL Paper run the same strategy on different exchange price feeds (Coinbase vs Hyperliquid). Over 112 live trades, they disagree on direction **21.6% of the time** and one is flat while the other is positioned on **76 additional bars**. HL Paper is significantly outperforming CB Live in this period.

The hypothesis: combining signals from BOTH feeds could filter out the noisy conflicting signals and produce higher-conviction entries.

**Goal:** Backtest 3 dual-feed strategy variants on historical data where both HL and CB candles are available (July–Dec 2025).

## Prerequisites

Both datasets must exist on the VM:
- HL/Binance 30m candles: `local-data/BTC_30m.parquet`, `ETH_30m.parquet`, `SOL_30m.parquet`
- Coinbase 30m candles: `local-data/BTC_30m_coinbase.parquet`, `ETH_30m_coinbase.parquet`, `SOL_30m_coinbase.parquet`

If the CB parquet files don't exist, run: `uv run engine/backtest.py --interval 30m --sourceoinbase --split test` to download them first.

## Data Alignment

Before running any variant, you need a helper that loads both feeds and aligns them by timestamp:

```python
# strategies/30m-concentrated/dual_feed_loader.py
"""
Loads and time-aligns HL and CB candle data for dual-feed strategies.
Returns merged DataFrames with columns suffixed _hl and _cb.
"""
import pandas as pd
from pathlib import Path

DATA_DIR = Path(__file__).resolve().parents[2] / "local-data"


def load_dual_candles(symbol: str) -> pd.DataFrame:
    """Load HL and CB candles, merge on timestamp, return only overlapping bars."""
    hl_path = DATA_DIR / f"{symbol}_30m.parquet"
    cb_path = DATA_DIR / f"{symbol}_30m_coinbase.parquet"

    hl = pd.read_parquet(hl_path).rename(columns={
        "open": "open_hl", "high": "high_hl", "low": "low_hl",
        "close": "close_hl", "volume": "volume_hl",
    })
    cb = pd.read_parquet(cb_path).rename(columns={
        "open": "open_cb", "high": "high_cb", "low": "low_cb",
        "close": "close_cb", "volume": "volume_cb",
    })

    # Keep only columns we need
    hl = hl[["timestamp", "open_hl", "high_hl", "low_hl", "close_hl", "volume_hl"]]
    cb = cb[["timestamp", "open_cb", "high_cb", "low_cb", "close_cb", "volume_cb"]]

    # Inner join on timestamp — only bars where both feeds have data
    merged = pd.merge(hl, cb, on="timestamp", how="inner").sort_values("timestamp").reset_index(drop=True)

    # Add funding rate from HL if available
    hl_full = pd.read_parquet(hl_path)
    if "funding_rate" in hl_full.columns:
        funding = hl_full[["timestamp", "funding_rate"]]
        merged = pd.merge(merged, funding, on="timestamp", how="left")
        merged["funding_rate"] = merged["funding_rate"].fillna(0.0)
    else:
        merged["funding_rate"] = 0.0

    return merged
```

## Option A: Consensus Filter

**Thesis:** Only enter when BOTH feeds' indicators agree on direction. Filters out the ~22% conflicts. Fewer trades but higher conviction.

```python
# strategies/30m-concentrad/strategy_consensus.py
"""
Dual-feed consensus: only enter when both HL and CB indicators agree.
Runs the 5 indicator votes on both price feeds independently.
Entry requires MIN_VOTES on BOTH feeds + HTF confirmation on BOTH.
"""
import numpy as np
import importlib.util
from pathlib import Path
from prepare import Signal, PortfolioState, BarData

# Load base strategy for its indicator functions and parameters
_base_path = Path(__file__).parent / "strategy.py"
_spec = importlib.util.spec_from_file_location("base_strategy", str(_base_path))
_mod = importlib.util.module_from_spec(_spec)
_spec.loader.exec_module(_mod)

# Import all parameters from base
MIN_VOTES = _mod.MIN_VOTES  # 3
SHORT_WINDOW = _mod.SHORT_WINDOW
MED_WINDOW = _mod.MED_WINDOW
EMA_FAST = _mod.EMA_FAST
EMA_SLOW = _mod.EMA_SLOW
RSI_PERIOD = _mod.RSI_PERIOD
RSI_BULL = _mod.RSI_BULL
RSI_BEAR = _mod.RSI_BEAR
MACD_FAST = _mod.MACD_FAST
MACD_SLOW = _mod.MACD_SLOW
MACD_SIGNAL = _mod.MACD_SIGNAL
HTF_EMA_FAST = _mod.HTF_EMA_FAST
HTF_EMA_SLOW = _mod.HTF_EMA_SLOW
HTF_MOM_WINDOW = _mod.HTF_MOM_WINDOW
HTF_MIN_VOTES = _mod.HTF_MIN_VOTES
BASE_POSITION_PCT = _mod.BASE_POSITION_PCT
TAKE_PROFIT_PCT = _mod.TAKE_PROFIT_PCT
ATR_STOP_MULT = _mod.ATR_STOP_MULT
ATR_LOOKBACK = _mod.ATR_LOOKBACK
COOLDOWN_BARS = _mod.COOLDOWN_BARS
MIN_HISTORY = _mod.MIN_HISTORY
ACTIVE_SYMBOLS = _mod.ACTIVE_SYMBOLS
SYMBOL_WEIGHTS = _mod.SYMBOL_WEIGHTS

ema_calc = _mod.ema_calc
calc_rsi = _mod.calc_rsi


def compute_votes(closes):
    """Compute bull_votes and bear_votes from a close price series."""
    dyn_threshold = 0.009
    ret_short = (closes[-1] - closes[-MED_WINDOW]) / closes[-MED_WINDOW]
    ret_vshort = (closes[-1] - closes[-SHORT_WINDOW]) / closes[-SHORT_WINDOW]

    mom_bull = ret_short > dyn_threshold
    mom_bear = ret_short < -dyn_threshold
    vshort_bull = ret_vshort > dyn_threshold * 0.7
    vshort_bear = ret_vshort < -dyn_threshold * 0.7

    ema_fast_arr = ema_calc(closes[-(EMA_SLOW + 10):], EMA_FAST)
    ema_slow_arr = ema_calc(closes[-(EMA_SLOW + 10):], EMA_SLOW)
    ema_bull = ema_fast_arr[-1] > ema_slow_arr[-1]
    ema_bear = ema_fast_arr[-1] < ema_slow_arr[-1]

    rsi = calc_rsi(closes, RSI_PERIOD)
    rsi_bull = rsi > RSI_BULL
    rsi_bear = rsi < RSI_BEAR

    # MACD
    if len(closes) >= MACD_SLOW + MACD_SIGNAL:
        ema_f = ema_calc(closes[-(MACD_SLOW + MACD_SIGNAL + 5):], MACD_FAST)
        ema_s = ema_calc(closes[-(MACD_SLOW + MACD_SIGNAL + 5):], MACD_SLOW)
        macd_line = ema_f - ema_s
        signal_line = ema_calc(macd_line, MACD_SIGNAL)
        macd_hist = macd_line[-1] - signal_line[-1]
    else:
        macd_hist = 0.0
    macd_bull = macd_hist > 0
    macd_bear = macd_hist < 0

    bull = sum([mom_bull, vshort_bull, ema_bull, rsi_bull, macd_bull])
    bear = sum([mom_bear, vshort_bear, ema_bear, rsi_bear, macd_bear])
    return bull, bear


def compute_htf(closes):
    """Compute higher-timeframe trend direction."""
    if len(closes) < HTF_EMA_SLOW + 10:
        return 0
    ema_f = ema_calc(closes[-(HTF_EMA_SLOW + 10):], HTF_EMA_FAST)
    ema_s = ema_calc(closes[-(HTF_EMA_SLOW + 10):], HTF_EMA_SLOW)
    ema_bull = ema_f[-1] > ema_s[-1]
    mom = (closes[-1] - closes[-HTF_MOM_WINDOW]) / closes[-HTF_MOM_WINDOW]
    mom_bull = mom > 0

    if len(closes) >= MACD_SLOW + MACD_SIGNAL:
        ema_ff = ema_calc(closes[-(MACD_SLOW + MACD_SIGNAL + 5):], MACD_FAST)
        ema_ss = ema_calc(closes[-(MACD_SLOW + MACD_SIGNAL + 5):], MACD_SLOW)
        ml = ema_ff - ema_ss
        sl = ema_calc(ml, MACD_SIGNAL)
        macd_bull = (ml[-1] - sl[-1]) > 0
    else:
        macd_bull = False

    bull_v = sum([ema_bull, mom_bull, macd_bull])
    bear_v = sum([not ema_bull, not mom_bull, not macd_bull])
    if bull_v >= HTF_MIN_VOTES:
        return 1
    elif bear_v >= HTF_MIN_VOTES:
        return -1
    return 0


class Strategy:
    """
    Dual-feed consensus strategy.
    
    The backtester passes BarData with the CB close prices.
    This strategy ALSO loads HL close prices from the dual_feed_loader
    and requires both feeds to agree before entering.
    
    NOTE FOR BACKTESTER INTEGRATION:
    The backtester needs to be modified to pass dual-feed data, OR
    this strategy needs to load HL data directly from parquet files
    and align by timestamp. The latter is simpler — see on_bar().
    """
    def __init__(self):
        self._base = _mod.Strategy()
        # Load HL candle data for cross-referencing
        from dual_feed_loader import load_dual_candles
        self._dual_data = {}
        for sym in ACTIVE_SYMBOLS:
            try:
                self._dual_data[sym] = load_dual_candles(sym)
            except Exception as e:
                print(f"Warning: could not load dual data for {sym}: {e}")

    def on_bar(self, bar_data, portfolio):
        """
        Run base strategy logic but gate entries on dual-feed consensus.
        Exit logic (stops, TP, RSI) uses CB data only (since that's where we execute).
        """
        signals = []
        self._base.bar_count += 1
        equity = portfolio.equity if portfolio.equity > 0 else portfio.cash

        for symbol in ACTIVE_SYMBOLS:
            if symbol not in bar_data:
                continue
            bd = bar_data[symbol]
            if len(bd.history) < MIN_HISTORY:
                continue

            cb_closes = bd.history["close"].values
            mid = bd.close
            current_pos = portfolio.positions.get(symbol, 0.0)

            # Get HL closes at the same timestamp
            hl_closes = None
            if symbol in self._dual_data:
                dual = self._dual_data[symbol]
                mask = dual["timestamp"] <= bd.timestamp
                if mask.sum() >= MIN_HISTORY:
                    hl_closes = dual.loc[mask, "close_hl"].values[-len(cb_closes):]

            # Compute votes on BOTH feeds
            cb_bull, cb_bear = compute_votes(cb_closes)
            cb_htf = compute_htf(cb_closes)

            if hl_closes is not None and len(hl_closes) >= MIN_HISTORY:
                hl_bull, hl_bear = compute_votes(hl_closes)
                hl_htf = compute_htf(hl_closes)
            else:
                # Fallback: if no HL data, just use CB (degrade gracefully)
                hl_bull, hl_bear = cb_bull, cb_bear
                hl_htf = cb_htf

            # CONSENSUS: both must agree
            bullish = (cb_bull >= MIN_VOTES and hl_bull >= MIN_VOTES and
                       cb_htf >= 1 and hl_htf >= 1)
            bearish = (cb_bear >= MIN_VOTES and hl_bear >= MIN_VOTES and
                       cb_htf <= -1 and hl_htf <= -1)

            weight = SYMBOL_WEIGHTS.get(symbol, 1.0 / 3)
            size = equity * BASE_POSITION_PCT * weight

            # Exit logic — delegate to base strategy's exit rules (uses CB data)
            # We need to handle existing positions using the base strategy's
            # stop/TP/RSI logic, which only needs the execution feed (CB)
            if current_pos != 0:
                # Let the base strategy handle exits — it will return exit signals
                # We just need to gate NEW entries on consensus
            base_signals = self._base.on_bar(bar_data, portfolio)
                # Pass through any exit signals (target_position=0) directly
                # Only gate entry signals on consensus
                for sig in (base_signals or []):
                    if sig.symbol != symbol:
                        continue
                    if sig.target_position == 0:
                        signals.append(sig)  # exit — always allow
                    elif bullish and sig.target_position > 0:
                        signals.append(sig)  # long entry — consensus confirmed
                    elif bearish and sig.target_position < 0:
                        signals.append(sig)  # short entry — consensus confirmed
                    # else: entry blocked by consensus filter
                continue

            # New entry — requires consensus
            in_cooldown = (self._base.bar_count - self._base.exit_bar.get(symbol, -999)) < COOLDOWN_BARS
            if in_cooldown:
                continue

    if bullish:
                signals.append(Signal(symbol=symbol, target_position=size,
                    metadata={"cb_bull": cb_bull, "hl_bull": hl_bull, "cb_htf": cb_htf, "hl_htf": hl_htf}))
                self._base.entry_prices[symbol] = mid
                self._base.peak_prices[symbol] = mid
                self._base.atr_at_entry[symbol] = self._base._calc_atr(bd.history, ATR_LOOKBACK) or mid * 0.02
            elif bearish:
                signals.append(Signal(symbol=symbol, target_position=-size,
                    metadata={"cb_bear": cb_bear, "hl_bear": hl_bear, "cb_htf": cb_htf, "hl_htf": hl_htf}))
                self._base.entry_prices[symbol] = mid
                self._base.peak_prices[symbol] = mid
                self._base.atr_at_entry[symbol] = self._base._calc_atr(bd.history, ATR_LOOKBACK) or mid * 0.02

        return signals
```

## Option B: Combined 10-Vote Pool

**Thesis:** Pool all 5 indicators from both feeds into 10 total votes. Require 7/10 to enter. Naturally smooths exchange noise.

```python
# strategies/30m-concentrated/strategy_10vote.py

Dual-feed 10-vote pool: 5 indicators from CB + 5 from HL = 10 votes.
Requires 7/10 for entry (vs 3/5 in base strategy).
"""

        equity = portfolio.equity if portfolio.equity > 0 else portfolio.cash

        for symbol in ACTIVE_SYMBOLS:
            if symbol not in bar_data:
                continue
            bd = bar_data[symbol]
            if len(bd.history) < MIN_HISTORY:
                continue

            cb_closes = bd.history["close"].values
            mid = bd.close
            current_pos = portfolio.positions.get(symbol, 0.0)

            # Get HL closes
          hl_closes = None
            if symbol in self._dual_data:
                dual = self._dual_data[symbol]
                mask = dual["timestamp"] <= bd.timestamp
                if mask.sum() >= MIN_HISTORY:
                    hl_closes = dual.loc[mask, "close_hl"].values[-len(cb_closes):]

            # Compute votes on both feeds
            cb_bull, cb_bear = compute_votes(cb_closes)
            cb_htf = compute_htf(cb_closes)

            if hl_closes is not None and len(hl_closes) >= MIN_HISTORY:
                hl_bull, hl_bear = compute_votes(hl_closes)
                hl_htf = compute_htf(hl_closes)
            else:
                hl_bull, hl_bear = cb_bull, cb_bear
                hl_htf = cb_htf

            # COMBINED: pool votes from both feeds
            total_bull = cb_bull + hl_bull  # out of 10
            total_bear = cb_bear + hl_bear
            # HTF: require at least one feed to confirm
            htf_bull = cb_htf >= 1 or hl_htf >= 1
            htf_bear = cb_htf <= -1 or hl_htf <= -1

            bullish = total_bull >= COMBINED_MIN_VOTES and htf_bull

                        signals.append(sig)
                    elif bullish and sig.target_position > 0:
                        signals.append(sig)
                    elif bearish and sig.target_position < 0:
                        signals.append(sig)
                continue

            in_cooldown = (self._base.bar_count - self._base.exit_bar.get(symbol, -999)) < COOLDOWN_BARS
            if in_cooldown:
                continue

            if bullish:
                signals.append(Signal(symbol=symbol, target_position=size,
                    metadata={"total_bull": total_bull, "cb_bull": cb_bull, "hl_bull": hl_bull}))
                self._base.entry_prices[symbol] = mid
                self._base.peak_prices[symbol] = mid
                self._base.atr_at_entry[symbol] = self._base._calc_atr(bd.history, ATR_LOOKBACK) or mid * 0.02
            elif bearish:
                signals.append(Signal(symbol=symbol, target_position=-size,
                    metadata={"total_bear": total_bear, "cb_bear": cb_bear, "hl_bear": hl_bear}))
                self._base.entry_prices[symbol] = mid
                self._base.peak_prices[symbol] = mid
                self._base.atr_at_entry[symbol] = self._base._calc_atr(bd.history, ATR_LOOKBACK) or mid * 0.02
```

## Option C: HL Signal, CB Execution

**Thesis:** Use HL price data for ALL signal generation (since HL Paper is outperforming). Execute on CB data (since that's where the money is). The strategy "thinks" it's trading on Hyperliquid but the fills happen on Coinbase.

```python
# strategies/30m-concentrated/strategy_hl_signal.py
"""
HL signal, CB execution: generates signals from HL candle data
but returns them for execution on Coinbase.

The backtester feeds CB candles (for fill simulation and P&L).
This strategy overrides the signal generation to use HL candles instead,
while using CB prices for position management (stops, TP, entries).
"""
import numpy as np
import importlib.util
from pathlib import Path
from prepare import Signal, PortfolioState, BarData

_base_path = Path(__file__).parent / "strategy.py"
_spec = importlib.util.spec_from_file_location("base_strategy", str(_base_path))
_mod = importlib.util.module_from_spec(_spec)
_spec.loader.exec_module(_mod)

from strategy_consensus import (
    compute_votes, compute_htf, ACTIVE_SYMBOLS, SYMBOL_WEIGHTS,
    BASE_POSITION_PCT, COOLDOWN_BARS, ATR_LOOKBACK, MIN_HISTORY,
    MIN_VOTES,
)


class Strategy:
    def __init__(self):
        self._base = _mod.Strategy()
        from dual_feed_loader import load_dual_candles
        self._dual_data = {}
        for sym in ACTIVE_SYMBOLS:
            try:
                self._dual_data[sym] = load_dual_candles(sym)
            except Exception as e:
                print(f"Warning: could not load dual data for {sym}: {e}")

    def on_bar(self, bar_data, portfolio):
        signals = []
        self._base.bar_count += 1
        equity = portfolio.equity if portfolio.equity > 0 else portfolio.cash

        for symbol in ACTIVE_SYMBOLS:
            if symbol not in bar_data:
                continue
            bd = bar_data[symbol]
            if len(bd.history) < MIN_HISTORY:
                continue

            cb_closes = bd.history["close"].values
            mid = bd.close  # CB price — used for execution/stops
            current_pos = portfolio.positions.get(symbol, 0.0)

            # Get HL closes for SIGNAL GENERATION
            hl_closes = None
            if symbol in self._dual_data:
                dual = self._dual_data[symbol]
                mask = dual["timestamp"] <= bd.timestamp
                if mask.sum() >= MIN_HISTORY:
                    hl_closes = dual.loc[mask, "close_hl"].values[-200:]

            # Use HL for signals, fall back to CB if unavailable
            signal_closes = hl_closes if (hl_closes is not None and len(hl_closes) >= MIN_HISTORY) else cb_closes

            bull_votes, bear_votes = compute_votes(signal_closes)
            htf_dir = compute_htf(signal_closes)

            bullish = bull_votes >= MIN_VOTES and h_dir >= 1
            bearish = bear_votes >= MIN_VOTES and htf_dir <= -1

            weight = SYMBOL_WEIGHTS.get(symbol, 1.0 / 3)
            size = equity * BASE_POSITION_PCT * weight

            # Exits: use CB prices (since that's where positions are)
            if current_pos != 0:
                # Delegate exit logic to base strategy with CB data
                base_signals = self._base.on_bar(bar_data, portfolio)
                for sig in (base_signals or []):
                    if sig.symbol != symbol:
                        continue
                    if sig.target_position == 0:
                        signals.append(sig)  # exits always based on CB
                    elif bullish and sig.target_position > 0:
                        signals.append(sig)  # HL says go long
                    elif bearish and sig.target_position < 0:
                        signals.append(sig)  # HL says go short
                continue

            in_cooldown = (self._base.bar_count - self._base.exit_bar.get(symbol, -999)) < COOLDOWN_BARS
            if in_cooldown:
                continue

            # Entries: based on HL signals
            if bullish:
                signals.append(Signal(symbol=symbol, target_position=size,
                    metadata={"feed": "HL", "bull_votes": bull_votes, "htf": htf_dir}))
                self._base.entry_prices[symbol] = mid  # CB price for stops
                self._base.peak_prices[symbol] = mid
                self._base.atr_at_entry[symbol] = self._base._calc_atr(bd.history, ATR_LOOKBACK) or mid * 0.02
            elif bearish:
                signals.append(Signal(symbol=symbol, target_position=-size,
                    metadata={"feed": "HL", "bear_votes": bear_votes, "htf": htf_dir}))
                self._base.entry_prices[symbol] = mid
                self._base.peak_prices[symbol] = mid
                self._base.atr_at_entry[symbol] = self._base._calc_atr(bd.history, ATR_LOOKBACK) or mid * 0.02

        return signals
```

## Important Notes

- **Do NOT modify the live strategy, trader.py, or any cron jobs**
- All new files go in `strategies/30m-concentrated/`
- The `dual_feed_loader.py` must be in the same directory as the strategy files
- Use `--source coinbase` so the backtester feeds CB candles to the strategy (the strategy loads HL data separately from parquet)
- The exit logic in all 3 variants uses CB data (stops, TP, RSI) since that's where execution happens
- Each variant calls `self._base.on_bar()` for exit handling — this means the base strategy's internal state (entry_prices, peak_prices, etc.) must be kept in sync. The implementations above handle this.
- Results go in `strategies/30m-concentrated/results.tsv`
- If any variant's Sharpe exceeds CB baseline by >15%, it's worth deploying as a paper instance for live validation
